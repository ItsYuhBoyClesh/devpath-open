# Contributing

Learners, teachers and developers are welcome.

1. Open an issue explaining the problem or improvement.
2. Make focused changes and explain how to test them.
3. Submit a pull request.
4. Preserve licence notices and third-party credit.
5. Never include secrets, personal data or materials you do not have permission to contribute.

Contributions may be distributed under the MIT License. Contributors retain copyright in their own qualifying original work; no copyright assignment is required. Maintainers may request changes or decline submissions.
