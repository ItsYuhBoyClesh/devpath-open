# DevPath Open

> An **Open Heightz** initiative, founded by **Clesh TN Maluleka**.

Free, offline-friendly lessons and interactive quizzes for beginner developers. Version 0.1 community starter.

## Quick start
Download this repository and open `index.html` in a modern browser. Choose a lesson and test your understanding. No login, API key, tracking or installation required.

## Contents
Four introductory lessons: Python variables, Python conditions, semantic HTML and Git commits.
