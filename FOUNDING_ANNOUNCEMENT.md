# Open Heightz | Founding release announcement

**Technology Belongs to Everyone.**

Open Heightz is an emerging open-source initiative founded by **Clesh TN Maluleka** to help learners, developers, educators, communities and businesses access practical technology.

## Five public starter projects
- **DevPath Open**: beginner coding lessons and short quizzes.
- **AccessCheck Lite**: checks for several common HTML accessibility problems.
- **DocForge**: a local Python tool for building project inventories.
- **RepoGuardian**: a local scanner for potential secrets and basic repository hygiene.
- **OfflineFirst Kit**: a simple offline-capable note-taking starter app.

All are publicly accessible through [the project directory](OPEN_HEIGHTZ.md). They are early-stage tools with documented limitations, not certified or production-hardened solutions.

## Invitation
Try something. Report what breaks. Suggest a feature. Teach someone what you learned. Help translate a guide. Businesses and institutions are welcome to pilot these resources responsibly and give feedback.

We acknowledge the initiative founder while recognizing each contributor's independent work. Collaboration and honest attribution matter more than vanity metrics.
